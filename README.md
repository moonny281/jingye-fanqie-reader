# 净页番茄墨水屏阅读器 (jingye-fanqie-reader) · v0.4.4

专为墨水屏（E-Ink）设备与极简阅读爱好者深度定制的 **番茄小说全本离线下载 + 原生多级目录导出 + 微信读书风 1-bit 纯黑白线性阅读器** 一体化 Android 客户端（附带可选 Python 后端服务）。

## v0.4.4 版本核心更新说明 (Release Notes)

### 1. 重构番茄多级目录探测（严格区分一级分卷目录与二级章节目录）

* **一级目录（分卷 `Level 1`）与二级目录（章节 `Level 2`）精准分离**：

  * 修复了旧版 `volumeIndex` 在 `0-based` 与 `1-based` 之间混用导致第一卷卷名错位或丢失的问题；

  * 新增 `FanqieVolume`（一级分卷：`index`、`name`、`chapterCount`、`level=1`）与 `FanqieChapterItem`（二级章节：`index`、`indexInVolume`、`volumeIndex`、`volumeName`、`itemId`、`level=2`）完整层级数据模型。

* **消除网文正文标记与目录切分冲突**：

  * 旧版采用 `【章节名】` 标记章节，容易与网文正文中的 `【叮！系统面板】`、`【作家的话】` 发生正则冲突导致目录错乱；

  * `v0.4.4` 升级为互不冲突的专用标记：**一级分卷**采用 `=== 第X卷 卷名 ===`（并写入独立卷首字节区间），**二级章节**采用 `### 第X章 章节名 ###`，并对未带序号的原始章节名自动补全 `第X章 ` 前缀、自动去重 `第1章 第1章`。

* **前后端多级目录树状展示与折叠预览**：

  * **阅读器内目录页（`ChapterListAdapter`）**：一级分卷采用纯黑底白字粗体横幅（`◆ [一级分卷] 第X卷 卷名` + 右侧本卷章数与字数），二级章节采用纯白底黑字 + `1dp` 底部黑线 + `├─` 树状缩进前缀；

  * **番茄下载页与书架管理菜单（`FanqieActivity` / `FanqieUiHelper`）**：新增 **「目录预览」** 按钮，弹出 1-bit 纯黑白线性可折叠树状目录弹窗（点击一级分卷可展开/收起二级章节列表，点击任意二级章节可直接定位跳读）。

### 2. 彻底修复「实际已下载完但检测仍提示有更新/待续却没东西可下」Bug

* **剔除 `serial_count` 幽灵章节**：

  * 番茄落地页中的 `serial_count` 常包含作者已删除、草稿或审核未通过的章节，数量往往大于真实目录 `chapterListWithVolume`；旧版使用 `maxOf(landingChapterCount, dirChapters.size)` 并填充 `itemId = null` 的占位章节，导致这些无 `itemId` 的幽灵章节永远无法下载，进度卡在 `N-k / N`；

  * `v0.4.4` 在 Android 客户端（`FanqieCrawler.kt`）与 Python 后端（`backend/core/crawler.py`）中统一以目录 API 返回的**真实可下载章节列表**为准，彻底停止填充 `itemId = null` 的幽灵章节。

* **基于真实 `itemId` 集合的精确更新对账与自动治愈（Auto-Heal）**：

  * `FanqieLegadoBridge.checkBookUpdate()` 改为拉取远端最新有效章节集合，逐章与本地缓存（同时兼容 `itemId` 与章节 `index`）精确比对，仅统计真正尚未缓存的有效章节；

  * 下载引擎在完成多轮 AppAPI 批量拉取与 Web 端兜底后，对远端确认为空内容的章节自动写入归档占位，不再反复触发假未完结；

  * 书架上旧版遗留显示 `续下(+N)` / `更新(+N)` 但实际已下完的书籍，点击按钮或执行更新检测即可**自动治愈为已完成状态**。

### 3. 微信读书墨水屏 1-bit 纯黑白线性 UI + 真实封面保留 + 局刷/全刷独立控制

* **1-bit 纯黑白线性视觉体系（保留真实图书封面）**：

  * 全局锁定纯白背景（`#FFFFFF`）、纯黑文字与 `1dp~2dp` 实线边框（`#000000`），移除一切灰阶阴影、渐变与水波纹动画；

  * **完整保留图书封面**：书架网格/列表、番茄搜索结果与书籍详情页均展示真实小说封面，内置 `ensureBookCoverAsync` 自动补全与本地持久化缓存；

  * **零动画 1-bit 线性菜单与控件**：书架右上角三点菜单、对话框、底部面板、复选框、单选框、开关按钮均采用 1-bit 黑白框线绘制（选中为纯黑实心白字 `[✓]`，关闭为纯白底黑框 `[ ]`）。

* **墨水屏残影消除（局刷 + 全刷双独立开关 + 页数间隔可调）**：

  * 点击书架、番茄页或阅读器顶部的 **「墨水屏刷新」** 按钮，可独立控制：

    1. **局部刷新清残影（翻页/弹窗关闭自动局刷）**：`[✓] 已开启` / `[ ] 已关闭`

    2. **全局刷新清残影（黑白反转闪烁深度清残影）**：`[✓] 已开启` / `[ ] 已关闭`

    3. **全局刷新间隔页数**：支持 `1 / 3 / 5 / 8 / 10 / 15 / 20 页` 一键切换，并提供「立即局刷」与「立即全刷」快捷按钮。

## 核心功能一览

| 功能模块 | 特性说明 | 
| ----- | ----- | 
| **原生多级目录抓取** | 自动抓取番茄官方一级目录（分卷）与二级目录（章节），注入伴生 `.toc.json` 字节偏移表与 Room 数据库，毫秒级直通加载 | 
| **秒开阅读 & 后台离线** | 点击「立即阅读」秒抓首章批次并打开阅读器；后台全本离线支持状态栏进度通知、随时暂停与断点续传 | 
| **精确更新对账** | 基于章节 `itemId` 集合精确核对远端新增章节，支持单本检测与书架全部番茄书籍一键批量检测续下 | 
| **双格式精排导出** | 支持导出含原生 NCX/Nav 多级分卷树状目录与封面的标准 `.epub`，以及含一级/二级目录索引表的精排 `.txt` | 
| **墨水屏极致优化** | 永久锁定墨水屏高对比度模式、全屏自适应阅读边距、可隐藏底部阅读进度条、局刷/全刷独立开关与隔页全刷机制 | 

## 构建与运行指南

### 1. Android 客户端编译

项目使用 **JDK 17** 与 **Android SDK 35** 构建：

```
chmod +x gradlew
./gradlew assembleAppRelease --no-daemon --stacktrace

```

编译产物位于 `app/build/outputs/apk/app/release/`。

### 2. GitHub Actions 手动构建与发布

仓库内 `.github/workflows/android-build.yml`、`test.yml`、`web.yml` 均已配置为仅允许手动触发（`workflow_dispatch`）：

1. 进入 GitHub 仓库的 **Actions** 页面；

2. 选择 **Build Android APK & Release** 工作流并点击 **Run workflow**；

3. 可选填入自定义版本号（留空则自动读取根目录 `VERSION` 文件 `0.4.4`），工作流将自动完成编译、生成 SHA-256 校验文件并发布 GitHub Release。

### 3. 可选 Python 后端服务运行

客户端默认内置全功能本地抓取引擎（无需部署后端即可独立搜书、下载、阅读与导出）。若需在局域网或服务器运行 Python Web 端：

```
pip install -r requirements.txt
python run.py

```

启动后默认监听 `http://0.0.0.0:5000`，可在客户端番茄页右上角点击「配置」填入后端地址切换。
