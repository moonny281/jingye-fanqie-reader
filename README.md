# 净页 (JingYe) · 海信 A7 墨水屏番茄小说阅读器 (`v0.3.1`)

专为 **海信 A7 墨水屏手机** 打造的极简黑白高对比度阅读器，深度集成 **[Jees996/fanqie-novel-downloader](https://github.com/Jees996/fanqie-novel-downloader)** 后端，采用 **微信读书墨水屏版 (WeRead E-Ink)** 视觉与精排体系。

---

## ✨ v0.3.1 核心升级亮点

### 1. 后台下载服务 + 状态栏实时进度通知 (`FanqieDownloadService` + `FanqieDownloadManager`)
- **独立前台服务下载**：点击下载后自动启动 `FanqieDownloadService`，即使退出搜书页面、返回书架或阅读其他小说，后台仍持续下载。
- **状态栏静默进度条**：在系统状态栏实时显示下载百分比与当前章节名（采用 `IMPORTANCE_LOW` + `setOnlyAlertOnce(true)`，避免墨水屏闪烁打扰），并支持直接在通知栏点击「暂停并存断点」。

### 2. 断点续下 + 书架检测更新与最新章节提示 (`ChapterCacheStore` + `checkBookUpdate`)
- **实时批次断点存档**：每下载完成一个批次（30 章）自动持久化章节缓存（`filesDir/chapter_cache/{bookId}.json`）并同步更新书架 TXT。
- **从上次中断处接着下**：无论主动暂停还是网络中断，再次点击「断点续下」时自动跳过已下载章节，直接从上次未下完的章节继续下载并合并全文。
- **书架一键检测更新**：书架顶部支持「检测更新」批量扫描，单本书籍卡片亦配备独立的「检测更新 / 断点续下 / 更新(+N)」按钮，实时展示番茄远端**最新章节名称**（如 `最新：第520章 xxx`）与新增章数。

### 3. 阅读界面支持「左右滑动手势翻页」(`PageView.onSwipeHorizontal`)
- 在阅读页面除点按左右区域、音量键翻页外，新增**手指往左滑动翻下一页、往右滑动翻上一页**手势识别（42dp 防误触阈值）。

### 4. 微信读书墨水屏版精致 UI 与内置多字体/预设排版 (`v0.3.0` + `v0.3.1`)
- 双层立体描边「最近在读」卡片、带书脊标签的墨水屏封面、书架实时后台下载状态条。
- 内置 6 款墨水屏字体（思源宋体、霞鹜文楷、思源黑体、墨水屏凝黑、古籍刻本、护眼柔黑）+ 本地 `.ttf/.otf` 导入，以及 5 套一键排版预设。
