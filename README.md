# 阅读Sigma (Legado-E) · 净页墨水屏深度优化与番茄小说全本下载聚合版 (`v0.3.2`)

本项目以 **`legado-E-main`（阅读Sigma 墨水屏版）** 为主体工程，深度聚合了 **[Jees996/fanqie-novel-downloader](https://github.com/Jees996/fanqie-novel-downloader)** 番茄小说全本下载内核与 **净页 (JingYe) 海信 A7 墨水屏专属优化组件**。

---

## ✨ 聚合版核心功能一览

### 1. 以 `Legado-E` 为主体的全能阅读体验 + 深度墨水屏优化 (`io.legado.app.eink.*`)
- **默认纯黑白 E-Ink 高对比度模式**：启动即默认开启 `Theme.EInk`（纯白 `#FFFFFF` 背景、纯黑 `#000000` 墨水字色、1.5dp 锐利描边、全局零过渡动画）。
- **左右滑动翻页抗抖动优化 (`NoAnimPageDelegate`)**：针对墨水屏无动画翻页模式专门优化水平净位移判定（32dp 阈值），**往左滑动翻下一页、往右滑动翻上一页**灵敏稳定，同时支持九宫格点按与音量键翻页。
- **海信 A7 自动全刷去残影 + 残影实验室 (`EinkRefreshHelper` / `EpdDebugActivity`)**：
  - 每翻页达到设定步长（默认 12 页，可调）自动触发黑白闪烁全刷清除电子墨水残影；
  - 阅读页顶部菜单新增「**墨水屏全刷清残影**」按钮与「**墨水屏全刷与残影实验室**」。
- **内置 6 款墨水屏专属字体 + 6 套微信读书墨水屏精排预设 (`BuiltinFontManager` / `readConfig.json`)**：
  - 阅读界面点击「界面 -> 字体」即可一键切换：**思源宋体**、**霞鹜文楷**、**思源黑体**、**墨水屏凝黑**、**古籍刻本**、**护眼柔黑**，并保留本地 `.ttf/.otf` 字体文件夹导入；
  - 内置 **微信精排**、**紧凑速读**、**舒朗大字**、**古籍雅致**、**高对比黑**、**护眼柔黑** 6 套墨水屏排版预设。

### 2. 原生内嵌番茄小说搜书、后台下载、断点续下与书架更新检测 (`io.legado.app.fanqie.*`)
- **书架顶部一键进入「番茄搜书/下载」(`FanqieActivity`)**：
  - 支持直接输入**书名或作者名关键字**多通道搜书，也支持粘贴番茄分享短链或 19 位 Book ID 解析；
- **后台下载服务 + 状态栏实时进度通知 (`FanqieDownloadService`)**：
  - 点击下载后在独立前台服务中运行，系统状态栏实时静默展示下载百分比与当前章节名，支持在通知栏直接点击「**暂停并存断点**」，下载期间可随时退回书架看书；
- **批次实时断点续下 (`FanqieChapterCacheStore` + `FanqieLegadoBridge`)**：
  - 每下载完成 30 章自动保存断点缓存并同步写入 Legado 书架数据库与章节表（无需等待全本下完即可边下边读）；
  - 下次点击「**断点续下**」自动跳过已缓存章节，直接从上次中断的章节接着往后下载；
- **书架检测更新按钮与最新章节提示 (`tv_fanqie_action` + `FanqieUiHelper`)**：
  - 书架上的番茄书籍右侧自带「**检测更新 / 断点续下(+N) / 更新(+N)**」按钮，并支持书架下拉刷新或菜单一键批量检测全部番茄书籍，实时展示远端**最新章节名称**。
