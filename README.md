# 阅读Sigma (`legado-E`) × 番茄小说墨水屏原生聚合版 (`v0.4.0`)

本工程以 **`legado-E`（阅读 Sigma 墨水屏版）** 为主体框架，深度内嵌 **[Jees996/fanqie-novel-downloader](https://github.com/Jees996/fanqie-novel-downloader)** 番茄小说全本搜书/解密引擎，并针对 **海信 A7（20:9）** 等电子墨水屏设备完成了原生级 UI 重绘与无缝阅读衔接。

## v0.4.0 核心修复与升级亮点

1. **彻底修复阅读时反复检查更新与弹出屏幕测试格 Bug**
   - 清理了 `ReadBookActivity.upMenu()` 遍历菜单项时的误触发分支，确保翻章、打开书籍或刷新菜单时绝不自动请求更新或弹出测试界面。
   - 废除了旧版棋盘格测试页，改为阅读器内嵌的 **「全刷清残影 / 全刷频率」** 原生设置弹窗（支持每 5/10/12/15/20/30 页自动全刷或一键手动全刷）。
   - 为番茄离线书籍隔离了 Legado 原生 `WebBook` 自动轮询，仅在用户主动点击「检测更新」或书架下拉刷新时按需检测。

2. **修复 20:9 墨水屏屏幕比例与全屏纸书画布**
   - 在 `AndroidManifest.xml` 中启用 `android:resizeableActivity="true"` 与 `android.max_aspect = 2.4`，并为 `FanqieActivity` 完整适配 `WindowInsets` 状态栏与导航栏安全边距。
   - 默认启用阅读页全屏纸书沉浸模式（`hideStatusBar = true`、`hideNavigationBar = true`、`paddingDisplayCutouts = true`），补齐 `readConfig_v040.json` 全部 6 套墨水屏预设（微信精排、紧凑速读、舒朗大字、古籍雅致、高对比黑、护眼柔黑）的完整页眉、页脚、分割线与边距参数。

3. **番茄与阅读无缝原生衔接（支持「立即阅读」秒开边看边下）**
   - **书架顶栏直达搜书**：在书架顶部直接内嵌微信读书墨水屏风格的「搜索番茄全网小说 / 番茄书城 / 检测更新」快捷栏，隐藏工程调试感的服务器配置框。
   - **秒开流式阅读**：在搜索结果或书籍详情页点击 **「立即阅读」**，1 秒内拉取前 8 章写入书架并直接打开原生阅读器开始阅读，同时后台服务自动静默续下剩余章节并实时热更新章节总数，实现真正的「边看边下」。
   - **真实封面与断点续下**：搜书列表与详情卡片均支持加载真实书籍封面、热门分类胶囊一键探索、状态栏进度通知以及每 30 章自动保存断点。

4. **原生墨水屏阅读器与书架 UI 重绘**
   - **阅读呼出菜单（`view_read_menu.xml`）**：彻底移除墨水屏下易留残影的半透明侧边竖向亮度条与 4 个带阴影的圆形 `FloatingActionButton`，重绘为纯白背景（`#FFFFFF`）+ `1.5dp` 纯黑实线边框的 **三层式原生墨水屏底栏**（第一层：全文搜索 / 自动翻页 / 全刷清残影 / 全刷频率 / 日夜反色 扁平线框胶囊；第二层：上一章 + 高对比进度条 + 下一章；第三层：目录 / 朗读 / 字体排版 / 设置）。
   - **正文墨水屏字形锐化（`ChapterProvider.kt`）**：关闭亚像素抗锯齿（`isSubpixelText = false`）并开启完整字形微调（`HINTING_ON`），内置 6 款墨水屏字体边缘锐利无灰边。
   - **书籍详情页（`BookInfoActivity`）**：移除 `#50000000` 半透明黑灰遮罩与圆弧阴影，改为纯白高对比墨水屏布局，并在底栏直接内嵌「检测番茄更新 / 断点续下」按钮。
